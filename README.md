# 木塞 - 潮汕两张半

在线地址：https://muse-game.onrender.com

## 玩法简介

潮汕地区经典扑克牌游戏，2-6人联网对战，含AI电脑玩家。

### 牌型等级（高到低）

双鬼至尊 > 天公9 > 天公8 > 豹子 > 同花顺 > 杂顺子 > 拼点数(9~1点) > 零点(吃双鬼)

### 倍率

| 牌型 | 倍率 |
|------|------|
| 双鬼至尊 | 10x |
| 豹子 | 8x |
| 同花顺 | 6x |
| 杂顺子 | 4x |
| 同花3张 | 3x |
| 同花天公/对子/同花2张 | 2x |
| 普通 | 1x |

### 鬼牌规则

- 每局亮一张牌决定鬼牌：亮出的牌同rank的其他花色为鬼
- 2张手牌时：鬼 = 任意花色的0点
- 3张手牌时：鬼可变任意牌凑特殊牌型（豹子/顺子/同花顺），凑不成则当0点

## 技术栈

- 后端：Node.js + Express + Socket.IO
- 前端：原生 HTML/CSS/JS
- 部署：Render
